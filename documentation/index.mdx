## What is it

`@frani/values-object` is a TypeScript library for creating and validating **value objects** for Brazilian documents. It encapsulates formatting rules, normalization, and check-digit validation into safe types ready to use in Node.js and browser applications.

## Features

- **Character** and **check-digit** validation
- Automatic normalization (strips masks and uppercases CNPJ letters)
- Custom errors identifiable via `instanceof` and `code`
- Zero runtime dependencies
- Exported TypeScript types

## Quick example

```typescript
import { CPF, CNPJ, InvalidCPFError, InvalidCNPJError } from "@frani/values-object";

const cpf = CPF.create("390.533.447-05");
console.log(cpf.value); // "39053344705"

const cnpj = CNPJ.create("12.ABC.345/01DE-35");
console.log(cnpj.value); // "12ABC34501DE35"

try {
  CPF.create("111.111.111-11");
} catch (error) {
  if (error instanceof InvalidCPFError) {
    console.log(error.code);  // "INVALID_CPF"
    console.log(error.value); // "111.111.111-11"
  }
}
```
